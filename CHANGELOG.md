# Changelog

## [1.0.0] - 2026-07-13

### Added
- Initial release of bm
- `bm add`, `bm go`, `bm list`, `bm del`, `bm path` commands
- Shell integration for automatic `cd` on `bm go`
- Bash completion for bookmark names
- Man page (`bm.1`)
- Debian packaging (3.0 native format)
- Automatic shell activation via `/etc/profile.d/` and `/etc/bash.bashrc`
- Maintainer scripts for clean install/remove
- Lintian-clean package
- Build scripts (with and without debhelper)
- GitHub Actions CI workflow
