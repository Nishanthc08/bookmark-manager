# Roadmap

## Short Term

- zsh completion support
- `bm rename` command for renaming bookmarks
- Fuzzy search on `bm go` (partial name match)

## Medium Term

- Export/import bookmarks (JSON format)
- `bm mv` / `bm cp` for bulk operations
- Colorized output with `--color` flag

## Long Term

- Sync bookmarks across machines via a config file
- Integration with `fzf` for interactive selection
- Tab completion for zsh and fish

## Non-Goals

- Frequency-based directory jumping (like z/fasd) — bm is explicit, not heuristic
- GUI — this is a terminal tool
