# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in bm, please do not open a public issue.
Instead, email the maintainer directly at nishu@example.com.

## Scope

Vulnerabilities in the packaged `.deb` or the shell integration scripts are in scope.
The tool runs as a regular user and does not require elevated privileges at runtime.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
